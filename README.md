CHANEL --- Rare Collection --- это одностраничный (SPA) интернет-магазин, вдохновлённой эстетикой бренда Chanel, предназначенный для продажи и продажи консервативных, архивных и лимитированных сумок. Сайт предоставляет возможность просмотра каталога товаров с динамической генерацией карточек, использования поиска, фильтрации и сортировки по различным параметрам.

При выборе цвета открывается модное окно с галереей изображений, описанием и деталями. Реализованы функции добавления в корзину и избранное, а также базовую систему аккаунта с регистрацией и входом. Оформление заказа включает в себя ввод данных, выбор способа оплаты и подтверждение.

Проект разработан без использования фреймворков на HTML5, CSS3 и чистом JavaScript, с применением Flexbox и Grid для адаптивной верстки, CSS-анимации и динамической работы через DOM. Данные о хранении данных в видео-массиве внутри JavaScript, что делает сайт полностью статичным и простым для запуска --- достаточно открыть файл index.html в браузере.
